# プロジェクト知識ベース

* [今どこにいるか](status.md) - 段階、基準線、問いごとの現在の最良、進行中の施策、実行中の計算
* [Question](questions/index.md) - 研究の問い
* [Proposal](proposals/index.md) - 施策の提案と状態。試して採用しなかったことの一覧もここ
* [Experiment](experiments/index.md) - 実験の結果・考察
* [Decision](decisions/index.md) - 採用・不採用などの判断とその理由
* [Architecture](architecture/index.md) - 構成・設計・評価の設計・マシンの記録
* [Reference](references/index.md) - 外部資料・論文・仕様などの参照メモ
* [履歴](log.md)

書き方は [docs/rules/okf.md](../docs/rules/okf.md) にある。各ディレクトリの index.md は `uv run scripts/index.py` が作る。
